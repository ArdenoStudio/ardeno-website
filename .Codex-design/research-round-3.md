# Ardeno entrance refinement

The brief evolved from a dense wall of tiny touching logos to a more considered introduction using the actual Ardeno A. The first dense interlock merged the silhouettes and was rejected. All current repeats now reference the original standalone SVG assets, upright, without modifying the mark.

## Research and application

- [Apple HIG: Motion](https://developer.apple.com/design/human-interface-guidelines/motion): purposeful, brief and precise motion; frequent interactions should not demand attention; motion should be optional and cancellable. Application: one focal mark, small movement, no repeated oscillation, replay/pause/skip in the lab and a still for reduced motion.
- [Apple WWDC23: Animate with springs](https://developer.apple.com/videos/play/wwdc2023/10158/): position and velocity continuity make movement natural; a spring does not need bounce; zero bounce is a versatile starting point. Application: critically damped physical spring, 9px translation and 2% scale on entry, no overshoot. No suggestion that Apple designed or endorsed these concepts.
- [Apple HIG: Loading](https://developer.apple.com/design/human-interface-guidelines/loading): display content quickly and let people continue while assets load. Application: keep ordinary site startup unchanged; current 1.05–1.25s sequences are reviewable brand-intro studies, not simulated network progress. A chosen implementation should yield when content is ready, play once, and preserve access to the page.
- [R–K portfolio process, by its creator on Codrops](https://tympanus.net/codrops/2026/04/07/r-k-26-the-thinking-and-code-behind-a-portfolio-led-by-presence/): connect the opening reveal to the ready hero underneath. Application: each preview reveals the existing page design rather than a disconnected loading screen.

## Design decision

Keep tiny touching As as a secondary texture. Use the unaltered large A for immediate recognition. Five compositions explore a signal mark on ink, an ink mark on paper, an off-centre paper mark on signal, a large A filled with tiny As, and a paper mark with a quiet split reveal.

Recommendation: I, A within A, answers the repeating-monogram brief with a clear silhouette and useful empty space. G, Paper press, offers the calmest handover to the website. These are aesthetic recommendations, not a universally proven best design.

## Subsequent user direction

The user preferred the background of J, Studio veil, and asked for variants with the same colour. K–O now focus on that background: keep the same Ink/Paper palette, original large A, focal composition and 1.1s timing; vary only arrangement, contrast, a passing pattern highlight, centre softness and density. K preserves the selected repeat; N gives the foreground mark more room. The comparison opens paused so the backgrounds can be inspected before playback.
